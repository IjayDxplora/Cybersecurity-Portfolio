This repository documents my hands-on cloud security engineering work across Identity & Access Management, Zero Trust architecture, Microsoft Azure security, SIEM operations, and infrastructure-as-code.

## 💡 Featured Work

### 🔐 Entra ID Hybrid Deployment (200 Users)
Architected and deployed Microsoft Entra ID for a 200-user hybrid environment. Engineered Conditional Access policies, MFA enforcement, and SSO integrations across 10+ SaaS platforms — eliminating identity gaps across cloud and on-premises. See: [01-IAM-Zero-Trust/Entra-ID-Hybrid-Deployment](./01-IAM-Zero-Trust/Entra-ID-Hybrid-Deployment/)

### 📈 Defender for Cloud Posture: 45% → 82% in 90 Days
Raised Microsoft Defender for Cloud secure score by 37 points through systematic misconfiguration remediation, network hardening, and compliance policy enforcement at scale. See: [02-Cloud-Security/Defender-for-Cloud-Hardening](./02-Cloud-Security/Defender-for-Cloud-Hardening/)

### 🔑 Privileged Identity Management — Zero Standing Privilege
Implemented PIM with just-in-time access controls for all administrative roles, eliminating standing privilege across 100% of cloud accounts and reducing lateral movement risk. See: [01-IAM-Zero-Trust/Privileged-Identity-Management](./01-IAM-Zero-Trust/Privileged-Identity-Management/)

### 📊 Microsoft Sentinel SIEM — MTTR Reduction 35%
Engineered and tuned Sentinel analytics rules and SOAR playbooks to automate response to recurring threat patterns, reducing mean time to respond by 35%. See: [03-Security-Operations/Microsoft-Sentinel-SIEM](./03-Security-Operations/Microsoft-Sentinel-SIEM/)
